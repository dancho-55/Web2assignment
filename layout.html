Task 2. Макет страницы

Именованные области Grid описывают структуру страницы: шапка сверху, навигация слева, контент справа и подвал снизу.

Сначала — структура

HTML задаёт смысл: header — шапка, aside — дополнительные материалы, main — основной контент, footer — подвал. CSS отвечает за их расположение.

Макет, который можно прочитать

Верхняя строка — "header header" , средняя — "sidebar main" , нижняя — "footer footer" . Повторение имени означает, что область занимает две колонки.

Больше свободы на маленьком экране

На ширине до 650 px сетка становится одноколоночной. Шапка, боковая панель, контент и подвал идут друг за другом.
