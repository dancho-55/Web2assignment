# Подготовка к защите

## Как объяснить проект за минуту

«В проекте пять страниц с общей навигацией. Flexbox использован для элементов вдоль одной оси: ссылок, ряда карточек и содержимого карточек. Grid задаёт двумерную структуру страницы и галерею. Общие цвета и отступы вынесены в переменные. На маленьком экране работают перенос Flexbox и медиазапросы. JavaScript не нужен: все действия — переходы по ссылкам».

## Основные свойства

- `justify-content` распределяет элементы по главной оси Flexbox. В шапке `space-between` раздвигает логотип и навигацию к краям.
- `align-items` выравнивает по поперечной оси. `center` в шапке центрирует по вертикали, а `stretch` в ряду растягивает карточки до высоты самой высокой карточки этой строки.
- `gap` задаёт промежутки между дочерними элементами Flexbox или Grid, не добавляя внешние отступы контейнеру.
- `flex-wrap: wrap` разрешает перенос элементов на следующую строку.
- `flex-direction` определяет главную ось. `row` располагает элементы горизонтально, `column` — вертикально. При `column` оси для justify-content и align-items меняются местами.
- `grid-template-columns` описывает колонки. `220px minmax(0, 1fr)` означает фиксированную боковую панель и основной блок, занимающий оставшееся пространство. Нулевой минимум позволяет колонке сжиматься.
- `grid-template-areas` задаёт схему именованных областей. Каждый текст в кавычках — строка сетки. Повтор имени объединяет соседние ячейки в прямоугольную область.
- `grid-template-rows` задаёт строки. В макете `auto 1fr auto`: высота шапки и подвала зависит от содержимого, центральная строка занимает оставшееся пространство.
- `fr` — доля свободного пространства в Grid. `repeat(3, minmax(0, 1fr))` создаёт три равные колонки.
- `flex: 1 1 280px` — сокращение grow, shrink и basis. Карточка может расти, сжиматься, а её исходный размер — 280 px.

## Почему карточки одинаковой высоты

Контейнер `.card-row` использует `align-items: stretch`. Карточки в одной строке растягиваются до общей высоты. Сама карточка — вертикальный flex-контейнер. `.card-body` имеет `flex: 1`, поэтому занимает оставшуюся высоту после изображения. `margin-top: auto` у кнопки забирает свободное место над ней. Благодаря этому кнопки стоят на одной нижней линии даже при разной длине текста. Фиксировать высоту текста не нужно. В разных перенесённых строках высота может различаться.

## Как работает адаптивность

`meta viewport` сообщает мобильному браузеру реальную ширину экрана. `box-sizing: border-box` включает padding и border в объявленный размер. Изображения не шире родителя, а `object-fit: cover` заполняет заданный прямоугольник с возможной обрезкой краёв.

У шапки и карточек есть `flex-wrap`. До 900 px галерея содержит две колонки. До 650 px галерея и большие Grid-макеты становятся одноколоночными; в макете Task 2 sidebar идёт до main, а в портфолио — после main. До 650 px также уменьшаются внешние отступы. Заголовки имеют обычные фиксированные размеры; на главной расположен простой список ссылок.

Скрыть переполнение через `overflow-x: hidden` было бы маскировкой: в проекте ширина контролируется сеткой, переносом и `min-width: 0`. `overflow: hidden` у карточек и изображений используется только для скругления и подписи.

## Доступность и действия

У сайта `lang="ru"`, один main и один h1 на страницу, смысловые header/nav/aside/footer. У изображений текстовые альтернативы. Текущая ссылка отмечена `aria-current="page"`, видимый фокус задан через `:focus-visible`. Первая ссылка позволяет пропустить меню.

Кнопки перехода реализованы элементом `a`, потому что ведут на страницу или к разделу. Для изменения состояния интерфейса подошёл бы `button`, но таких действий здесь нет. Галерея открывает локальные SVG. `:focus-within` показывает подпись, когда ссылка внутри figure получает фокус. Для `(hover: none)` или `(pointer: coarse)` подпись видна постоянно. Также она постоянно видна на ширине до 650 px.

## Вопросы и краткие ответы

1. **Чем Grid отличается от Flexbox?** Flexbox организует элементы вдоль главной оси; Grid позволяет явно управлять строками и колонками одновременно.
2. **Можно ли сочетать их?** Да: Grid задаёт макет страницы, Flexbox — содержимое карточек и меню.
3. **Почему не float?** Float нужен для обтекания, а не для этих макетов. Здесь современное выравнивание решается Flexbox и Grid.
4. **Почему gap удобнее margin?** Он задаёт равные внутренние промежутки без лишнего отступа у крайних элементов.
5. **Как footer занимает всю ширину?** Его имя повторяется в обеих колонках: `"footer footer"`.
6. **Что будет без flex-wrap?** Карточки останутся в одной строке и будут сжиматься; при достижении минимальных размеров возможно переполнение.
7. **Почему кнопки внизу?** Вертикальный Flexbox, растущий блок содержимого и автоматический верхний отступ кнопки.
8. **Зачем minmax(0, 1fr)?** Позволяет колонке сжиматься ниже её минимальной ширины по содержимому; длинный контент также нужно переносить.
9. **Что делает object-fit: cover?** Сохраняет пропорции изображения, заполняя весь блок и при необходимости обрезая края.
10. **Как обозначена текущая страница?** Через `aria-current="page"`; CSS оформляет эту ссылку отдельным цветом.
11. **Зачем CSS-переменные?** Чтобы менять общий цвет или отступ в одном месте для всех страниц.
12. **Почему сайт работает на GitHub Pages?** Это статические файлы с относительными путями; серверный код и сборка не нужны.
13. **Что значит каскад?** При одинаковой специфичности позднее правило выигрывает, поэтому медиазапросы расположены после основных правил.
14. **Как проверить адаптивность?** Изменить ширину в DevTools, проверить переносы, фокус, кнопки, загрузку изображений и отсутствие горизонтальной прокрутки.

## Пять упражнений для live coding

Вносите каждое изменение отдельно в конец `assets/css/tasks.css`, проверьте результат и удалите его перед следующим упражнением. HTML из упражнения 5 меняется в `cards.html`.

### 1. Увеличить промежуток между ссылками меню

Задача: сделать промежуток равным 16 px при стандартном размере шрифта.

```css
.nav-list {
  gap: 1rem;
}
```

Проверка: на широком экране расстояния одинаковы, на телефоне ссылки переносятся. Размер gap зависит от rem, поэтому учитывает пользовательский размер шрифта.

### 2. Расположить карточки одной колонкой до 800 px

```css
@media (max-width: 800px) {
  .card-row {
    flex-direction: column;
  }
  .card {
    flex-basis: auto;
  }
}
```

При смене оси flex-basis влияет уже на высоту, поэтому исходные 280 px сбрасываем. Проверка: при 768 px карточки одна под другой, при 1440 px — в ряд.

### 3. Сделать sidebar справа на широком экране Task 2

```css
@media (min-width: 651px) {
  .area-layout {
    grid-template-columns: minmax(0, 1fr) 220px;
    grid-template-areas:
      "header header"
      "main sidebar"
      "footer footer";
  }
}
```

Проверка: основной блок слева, sidebar справа, шапка и подвал на всю ширину. HTML не меняется; на телефоне действует прежний порядок. В реальном интерфейсе учитывайте, что порядок Tab следует HTML, а не визуальному расположению Grid.

### 4. Изменить галерею на четыре колонки

```css
@media (min-width: 901px) {
  .gallery {
    grid-template-columns: repeat(4, minmax(0, 1fr));
    grid-template-rows: none;
    grid-auto-rows: 200px;
  }
}
```

Проверка: строки содержат 4, 4 и 1 изображение. `grid-auto-rows` задаёт одинаковую высоту автоматически создаваемых строк. После упражнения верните исходные три колонки, которые нужны по заданию.

### 5. Добавить четвёртую карточку

Вставьте внутрь `.card-row` после последнего article:

```html
<article class="card">
  <img src="assets/images/study-04.svg"
       alt="Схема интерфейса с боковой панелью"
       width="620" height="400">
  <div class="card-body">
    <h2>Главная страница</h2>
    <p>Проверяю перенос и выравнивание меню на Flexbox.</p>
    <a class="button" href="index.html">Открыть главную</a>
  </div>
</article>
```

Проверка: изображение загружается, ссылка открывает главную, карточка переносится при нехватке места. Стили писать заново не нужно. Кнопки каждой отдельной строки остаются выровненными.
