# Assignment #2 — Advanced CSS: Flexbox & Grid

Простое учебное портфолио начинающего frontend-разработчика: пять отдельных страниц на чистых HTML5 и CSS3. JavaScript, фреймворков, зависимостей и сборки нет. Все изображения локальные; проект работает без интернета.

## Запуск

Откройте `index.html` двойным щелчком в браузере. Остальные страницы доступны через общую навигацию. Сохраняйте всю папку проекта, иначе относительные пути к стилям и изображениям перестанут работать.

Альтернатива, если установлен Python 3: откройте терминал в папке проекта, выполните `python3 -m http.server 8000` и откройте `http://localhost:8000`. Остановка сервера: Ctrl+C.

SVG — девять созданных для проекта схем интерфейсов. Это настоящие локальные изображения, подключённые через `img`, без внешних сервисов, лицензируемых фотографий или случайных URL. Три схемы структуры повторяются с разными цветовыми решениями. Их можно заменить своими скриншотами, сохранив правильные пути и обновив `alt`.

## Соответствие заданиям

| Задание | Страница | Основные селекторы |
| --- | --- | --- |
| 0. Navigation Bar | `index.html` и все страницы | `.site-header`, `.nav-list`: Flexbox, gap, align-items, flex-wrap |
| 1. Card Row | `cards.html` | `.card-row`, `.card`, `.card-body`: Flexbox, одинаковая высота, кнопки внизу |
| 2. Grid Areas | `layout.html` | `.area-layout`: две колонки, три строки, header/sidebar/main/footer |
| 3. Image Gallery | `gallery.html` | `.gallery`, `.gallery-item`: 9 изображений, Grid, overlay |
| 4. Combining Flexbox & Grid | `portfolio.html` | `.portfolio-layout`: Grid; `.project-card`: Flexbox |

На широком экране галерея 3 × 3, до 900 px — две колонки, до 650 px — одна. Основные макеты перестраиваются при 650 px. Карточки переносятся автоматически. В каждой flex-строке их высота одинаковая, между разными строками высота может отличаться.

Ссылки с `aria-current="page"` обозначают текущую страницу. Ссылка «К содержимому» появляется при Tab. У изображений есть `alt`, у ссылок — видимый фокус. Подписи галереи доступны при наведении, фокусе с клавиатуры и постоянно на сенсорных устройствах. Анимации и плавные переходы не используются.

## Публикация через GitHub Pages

Сайт пока **не опубликован**. Следующие действия выполняются в вашем аккаунте GitHub:

1. Создайте публичный репозиторий, например `assignment-2-frontend`.
2. Через **Add file → Upload files** загрузите **содержимое** папки `frontend-portfolio`: пять HTML-файлов, документацию, папку `assets` и `.nojekyll`. `index.html` должен лежать в корне репозитория, а не внутри `outputs/frontend-portfolio`.
3. Сохраните файлы коммитом в ветку `main`.
4. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Source → Deploy from a branch**.
5. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
6. Дождитесь успешного выполнения публикации во вкладке **Actions**. В **Settings → Pages** появится адрес сайта. Обычно это `https://ВАШ-ЛОГИН.github.io/assignment-2-frontend/` — замените логин и имя репозитория своими.
7. Откройте выданный GitHub адрес и проверьте все пять страниц, изображения и кнопки. Это обязательная отдельная проверка после публикации.
8. Для обновления сайта загрузите изменённые файлы и создайте новый коммит.

Шаги выбора источника публикации сверены с [официальной инструкцией GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
